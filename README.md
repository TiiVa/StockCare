# StockCare

## Den här applikationen har jag skapat som en hemuppgift inför min andra intervju för VGR:s Koncernstab Digitaliserings Traineeprogram. Applikationen möjliggör för användaren att skapa nya artiklar, uppdatera befintliga artiklar, göra uttag av material då även lagersaldot uppdateras samt visar varning om ett saldo börjar bli lågt alternativt om det hunnit bli kritiskt lågt. Den förhindrar att användaren gör ett uttag av material som medför för lågt saldo genom att inte tillåta uttag som resulterar i ett antal under minsta lagerantal med propertyn MinStockLevel
